Projets d'application

Chaque projet porte le nom de ses méthodes ; le jeu de données n'est que le cas pratique. Code, résultats et README sur GitHub.

  1. P1Boosting, validation et fuites

    boosting de gradient · validation temporelle · détection de fuite · importance par permutation

    Cas pratique : les retards de livraison (DataCo, 180 519 lignes). Fuite détectée et retirée ; 72,2 % d'exactitude et AUC de 0,774 sur le test.

  2. P2Clustering et différence de différences

    K-moyennes · ACP · différence de différences · tendances parallèles · test placebo

    Cas pratique : le vélo à Montréal. Trois profils de stations BIXI ; effet du REV Saint-Denis sur la piste Brébeuf : de −38 % à −64 % de passages.

  3. P3 à P7À venir

    Apprentissage profond avec PyTorch, Transformer, IA embarquée, réseaux de neurones sur graphe et affinage d'un modèle de langage ouvert.
