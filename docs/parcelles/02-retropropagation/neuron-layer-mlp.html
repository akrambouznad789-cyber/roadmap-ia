Les noms entourés de __ sont des méthodes que Python lance tout seul, comme __add__ et __mul__ dans la classe Value. En trafic : __init__, c'est bâtir l'échangeur ; __call__, c'est y faire passer une heure de trafic. On bâtit une fois, on fait passer du trafic autant qu'on veut.

Boîte 1

Neuron : une intersection

Trois rues entrent (x), chacune compte plus ou moins (w), il y a un trafic de base (b), et ce qui sort plafonne comme une capacité : toujours entre -1 et 1 (tanh).

class Neuron:

  def __init__(self, nin):
    self.w = [Value(random.uniform(-1,1)) for _ in range(nin)]
    self.b = Value(random.uniform(-1,1))

  def __call__(self, x):
    act = sum((wi*xi for wi, xi in zip(self.w, x)), self.b)
    out = act.tanh()
    return out

  def parameters(self):
    return self.w + [self.b]

Boîte 2

    
Layer : un rang d'intersections

    
Quatre intersections reçoivent toutes les mêmes trois rues. Chacune a ses propres réglages (w, b), donc chacune sort un débit différent.


    

      

        
        
        
        
      



class Layer:

  def __init__(self, nin, nout):
    self.neurons = [Neuron(nin) for _ in range(nout)]

  def __call__(self, x):
    outs = [n(x) for n in self.neurons]
    return outs[0] if len(outs) == 1 else outs

  def parameters(self):
    return [p for neuron in self.neurons for p in neuron.parameters()]

Boîte 3

    
MLP : la chaîne de montage

    
MLP veut dire multi-layer perceptron : un réseau à plusieurs couches. Ce qui sort d'un rang d'intersections devient le trafic qui entre dans le rang suivant.


    

      

        
        
        
        
      



class MLP:

  def __init__(self, nin, nouts):
    sz = [nin] + nouts
    self.layers = [Layer(sz[i], sz[i+1]) for i in range(len(nouts))]

  def __call__(self, x):
    for layer in self.layers:
      x = layer(x)
    return x

  def parameters(self):
    return [p for layer in self.layers for p in layer.parameters()]

x = [2.0, 3.0, -1.0]
n = MLP(3, [4, 4, 1])
n(x)


      

        

          
        

        

      


      

        

        

      

    

  


  
  

    
Ce que ces classes ne font pas

    

      

        
L'erreur classique

        
Layer(3, 4), ce n'est pas 3 neurones

        
Le 3, c'est combien d'entrées reçoit chaque neurone (nin). Le 4, c'est combien de neurones il y a (nout). Pareil dans MLP(3, [4, 4, 1]) : le 3 n'est pas une couche de neurones, c'est juste la taille de x.

      

      

        
Ce qu'elles ne font pas

        
Elles calculent, elles n'apprennent pas

        
MLP(...) construit le réseau avec des poids au hasard ; n(x) fait juste passer x dedans. Les poids ne bougent que dans la boucle d'entraînement qui vient après : la perte, loss.backward(), puis chaque p de n.parameters() fait un petit pas contre son grad. C'est pour ça que parameters() existe.
