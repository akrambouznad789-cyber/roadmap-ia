## Comment c'est fait

Chaque station suit les mêmes 4 étapes : regarder une ressource visuelle, explorer par le code sur un vrai cas, faire une pièce à la main, puis l'expliquer en mes mots.

Ces pages sont construites avec l'assistant Claude Code. Chaque page indique ce qui vient de moi et ce qui vient de l'IA.

## Ce que contient le dépôt

| Dossier | Contenu |
|---|---|
| `docs/` | Le site |
| `parcelles/` | Le code et les résultats de chaque station |
| `outils/` et `tests/` | De petits programmes qui mesurent, vérifient chaque page avant publication, et leurs tests |
| `gabarits/` | Le modèle de page des prochaines stations |
| `.claude/` | Les consignes de mon assistant IA : coach, quiz, publication |

Les données brutes ne sont pas dans le dépôt, seulement les résultats. Chaque source est créditée sur la page de sa station.
